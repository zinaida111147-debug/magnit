# Магнит

Планер для телефона: цели-магниты, день 1-3-5, привычки, деньги «сначала себе».

- **Android:** раздел Releases → `Magnit.apk`.
- **iPhone:** открыть ссылку GitHub Pages в Safari → «Поделиться» → «На экран Домой».

Данные хранятся только на телефоне. Перенос: «Сохранить копию файлом» в старой версии → «Восстановить из копии» в новой.
